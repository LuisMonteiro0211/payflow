# payflow 🔄️

Projeto em Python para simular métodos de pagamento (cartão, dinheiro, etc.), aplicando **taxas de desconto** e **juros** de acordo com o tipo de transação.  

Este repositório é um estudo prático para aplicar conceitos de:
- Programação Orientada a Objetos (POO)  
- Arquitetura MVC  
- Testes unitários  

A ideia é compartilhar minha evolução, erros e aprendizados durante o desenvolvimento 🚀  

---

## 🚀 Tecnologias
- 🐍 Python 3.12+
- 📊 Pytest (para testes)
